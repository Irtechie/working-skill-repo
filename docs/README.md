## Repository Boundary

Tracked files are product source, reusable tests/evals, and curated
documentation. Repository-maintenance todos, brainstorms, plans, handoffs, and
run results are local workflow state and are intentionally ignored here.

The skills still create those artifacts in consuming projects when project
memory or durable execution state is useful.
